# HomeMusic на Яндекс Станции Лайт

Мост «Алиса → HomeMusic» для рутованной Станции Лайт 1. Музыка **не кешируется**:
`ffmpeg` читает поток Navidrome/HomeMusic и сразу отдаёт PCM в `aplay`; на
`/data` лежат только очередь, позиция и логи.

## Что умеет

Фразы с явной привязкой к серверу:

- «Алиса, включи музыку через сервер» — случайные треки библиотеки;
- «Алиса, включи любимые через сервер» — ♥ из Navidrome/HomeMusic;
- «Алиса, включи плейлист <название> через сервер»;
- «Алиса, включи <исполнителя/трек> через сервер» — поиск;
- «Алиса, включи <трек> с нашего сервера» / «из HomeMusic».

Пока играет HomeMusic, обычные музыкальные команды идут в него:

- «следующий», «дальше», «переключи»;
- «предыдущий», «назад», «верни»;
- «пауза», «продолжи», «стоп», «выключи»;
- «лайк», «нравится», «дизлайк», «не нравится»;
- «перемешай», «вперемешку»;
- «громче», «тише»;
- «перемотай на 30 секунд», «назад на минуту».

Обычные фразы без «через сервер» не перехватываются, пока HomeMusic не играет:
Яндекс Музыка, Алиса, таймеры, умный дом и громкость работают как раньше. Если
во время HomeMusic попросить обычную музыку у Алисы, мост останавливает поток и
возвращает звук Яндексу.

## Установка на колонку

Нужны root, SSH на порту 2222 и Entware (`yse bootstrap`). На колонке:

```sh
/opt/bin/opkg install ffmpeg jq socat
mkdir -p /data/opt/homemusic
# скопировать сюда: hm-play.sh voice-bridge.sh command-watch.sh mediad-guard.sh
#                   alice-text.sh alice-text.awk
chmod 755 /data/opt/homemusic/*.sh
# config: SERVER=... USER=... PASSWORD=...
chmod 600 /data/opt/homemusic/config
```

Init-скрипт `S99zhomemusic` положить в `/etc/init.d/` (rootfs временно
перемонтировать в rw, затем обратно в ro) и выполнить:

```sh
/etc/init.d/S99zhomemusic start
```

Проверка:

```sh
/data/opt/homemusic/hm-play.sh status
tail -f /data/opt/homemusic/voice.log
/data/opt/homemusic/voice-bridge.sh --test 'Алиса, включи любимые через сервер'
```

Короткие заводские команды без «Алиса» («дальше», «лайк», «пауза», «тише»)
берутся из `maind.log` командным споттером (`command-watch.sh`) и действуют,
только пока играет HomeMusic.

`mediad-guard.sh` держит ровно один медиа-демон Алисы: пока играет HomeMusic,
`hm-play.sh` гасит его и забирает ALSA, а после остановки сторож поднимает один
`maind --mediad` обратно. Каждый демон берёт свой lock-каталог, поэтому
повторный `S99zhomemusic start` не плодит копии; после перезагрузки старые
lock-файлы и состояние плеера сбрасываются автоматически.

Остановка/откат:

```sh
/etc/init.d/S99zhomemusic stop
# удалить /etc/init.d/S99zhomemusic и /data/opt/homemusic
```

## Источник

`hm-play.sh` ходит в Subsonic API Navidrome (`/rest/...`) с администратором из
`config`; поток запрашивается как `format=mp3` и сразу декодируется. Ни один
трек не сохраняется на флешку. Для «любимых» используется `getStarred2`; для
поиска — `search3`; для плейлистов — `getPlaylists`/`getPlaylist`.
