# Что мы забрали из форков

База — `justman-1/HomeMusic-public`, сверху наш Ubuntu-порт, станция и переносы из форков.

## Забрали

| Источник | Что | Коммит | Состояние |
|---|---|---|---|
| **alenkimov** | Весь 2.0: версии, перенос музыки, «Качество звука», дискография, карта артистов, поиск, загрузки, статистика, «Найти другой файл» | merge `c255ffc` (292 коммита) | целиком |
| **DyshaGusew** | Чарты стран и жанров | `4cfc603` (их `b2502f7`) | переработано: фильтр Deezer-превью `no_full` |
| **DyshaGusew** | Чарты по настроениям: спокойное, энергичное, грустное, весёлое, романтичное, для фокуса | наш `charts.py` | переработано: личные треки + Deezer-плейлист как fallback, без обязательного Last.fm |
| **yelninx** | Поиск исполнителя в hitmoz: все треки, гости, перезаливы | `4cfc603` (их `b229a41`) | код совпадает |
| **a8tor** | Дедупликация волны: одна песня в одном батче, без повторного `nd:`/`dz:` и без копии того, что уже в очереди | наш `wave.py` | адаптировано: очередь не выкидываем, её копию — да |
| **a8tor / DyshaGusew** | Fallback поиска: если строгий ранкинг отсёк всё, остаются найденные файлы; `ignoreerrors` в yt-dlp | `jobs/downloads.py`, `providers/ytdlp.py` | взято |
| **Llirkit** | Выбор аудиовыхода (`setSinkId`), запоминание устройства, восстановление после перезапуска | `lib/audioOutput.ts`, `components/AudioOutput.tsx` | взято |
| **Llirkit** | Предзагрузка следующего трека целиком вторым буфером | `lib/audioPreload.ts`, `lib/listen.ts` | взято; в режиме «Станция» отключено |
| **Llirkit** | «Сменить аудио» в переносе | `pages/Import.tsx` | упрощённо: открывает наш «Найти другой файл» для уже сохранённого трека |

## Закрыто своим кодом

| Что у форка | Чем закрыто у нас |
|---|---|
| Llirkit: замена аудиоисточника | «Найти другой файл» + «Качество звука» + версии + корзина на 30 дней |
| a8tor: не повторять треки в волне | свой фильтр последних 10 треков (`eeee58f`) + новая дедупликация |
| a8tor: Linux VPS deployment | `install-ubuntu.sh`, `homemusic.sh` |

## Не забрали

| Источник | Что | Решение |
|---|---|---|
| a8tor | Обход HTTP 403 hitmos | **не нужно** — на сервере VPN |
| a8tor | `DELETE /downloads/items/{id}` | по желанию: у нас есть массовые `/remove` и `/clear` |
| a8tor | Таймауты поиска провайдеров, настройка энкодеров | потом |
| Llirkit | Миксы по настроению в ассистенте (`ai/mood.py`) | нет |
| Llirkit | Ручное создание дневного микса | частично: только rebuild |
| Llirkit | Hysteria VPN, Android Media3 | нет |
| ILexV | Десктоп на Rust + libmpv | нет |
| OranGeNaL | Полный отказ от Navidrome | нет, не подходит: станция играет из Navidrome |
| justman-1 | Android-клиент с выбором своего сервера | нет каталога `android/`; их APK совместим с нашим Hub |
| AnkouDW / PlayInSpirits / Dor0tos | Flow / AURA / Nuxt | отдельные продукты, не сливаем |
